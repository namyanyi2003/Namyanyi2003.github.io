What the Workspace Tests

The Case Workspace is used to inspect whether a mechanism-guided backend run can produce more structured human-state mapping than a surface-level response.

Did the user-state shift?

What route changed?

Runtime Boundaries

The Case Workspace does not claim universal human modeling. It does not provide diagnosis, therapy, clinical assessment, or professional judgment.

Boundary: bounded runtime workspace for inspecting mechanism-based backend inference under controlled local conditions.
