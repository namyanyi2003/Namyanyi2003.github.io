Reading note

How this archive should now be used

This site should no longer be approached as a theory-only homepage. It now exposes three public channels: theory, benchmark, and prototype.

The most accurate reading order for formal readers is usually Canonical Specification first, then Publications Pages 1–4, then Benchmark Records and Prototype Records as distinct downstream lines.

The benchmark line is not theory exposition, and the prototype line is not a replacement for canonical theory. Each channel preserves a different function within the archive.

Why this page matters

Research pages often fail by mixing theory explanation, archive logic, and evaluation surfaces into one blurred entry. This page separates those functions and clarifies where the formal entry points actually are.
